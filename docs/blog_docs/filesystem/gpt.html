GPT Partition Table

GUID Partition Table and Disk Organization

Overview

GPT (GUID Partition Table) is the modern partitioning standard. It replaces the legacy MBR with support for larger disks and more partitions.

GPT Structure

  • LBA 0 - Protective MBR (compatibility)
  • LBA 1 - GPT Header
  • LBA 2+ - Partition Entries (128 entries × 128 bytes)
  • Last sectors - Backup GPT (duplicate)

Key Takeaways

  • ✓ Supports 128 partitions
  • ✓ 64-bit LBA addressing (larger disks)
  • ✓ CRC32 checksums for integrity
  • ✓ GUID partition type identification
  • ✓ Backward compatible via protective MBR
