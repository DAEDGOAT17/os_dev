RTL8169 Network Controller

Realtek Gigabit Ethernet Controller Driver

Overview

The RTL8169 is a common gigabit Ethernet controller found in many systems. AOS provides full driver support for this hardware.

Hardware Features

  • Gigabit Ethernet (1000 Mbps)
  • PCI/PCIe interface
  • DMA-based packet transmission/reception
  • Interrupt-driven operation
  • Multiple RX/TX queues

Driver Initialization

  • Detect via PCI enumeration (vendor 0x10EC)
  • Enable PCI device and bus mastering
  • Map memory-mapped I/O base
  • Allocate RX/TX descriptor rings
  • Configure MAC address
  • Enable interrupts
  • Start packet reception

Key Takeaways

  • ✓ Gigabit Ethernet performance
  • ✓ DMA packet handling
  • ✓ Interrupt notification
  • ✓ PCI device auto-detection
  • ✓ Full lwIP stack integration
