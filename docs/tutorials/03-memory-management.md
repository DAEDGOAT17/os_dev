# Phase 3: Memory Management (Paging Hierarchy)\n\n> **Difficulty**: Intermediate to Advanced  \n> **Duration**: 60 minutes  \n> **Learning Goals**: Master physical allocation, 4-level paging, virtual-to-physical translation, and page fault handling\n\n---\n\n## Overview\n\nMemory management is the heart of modern operating systems. Without it, programs would collide in physical RAM, memory protection would be impossible, and the kernel couldn't enforce privilege levels.\n\nJarvis OS uses a **two-layer approach**:\n1. **Physical Memory Manager (PMM)** – Tracks which 4 KB blocks of physical RAM are in use via a bitmap\n2. **Virtual Memory Manager (VMM)** – Maps virtual addresses (used by programs) to physical addresses via 4-level paging\n\nThis phase covers:\n1. **Physical memory allocation** with bitmap tracking\n2. **4-level page table hierarchy** (PML4 → PDPT → PD → PT)\n3. **Virtual-to-physical address translation** with worked examples\n4. **Page fault handling** and error code interpretation\n5. **TLB invalidation** for page table updates\n\n---\n\n## 1. Physical Memory Manager (PMM)\n\n### Why a Bitmap?\n\nThe PMM must quickly track which physical pages are available for allocation. Jarvis OS uses a **bitmap**: one bit per 4 KB page.\n\n- **Bit = 0**: Page is free (available for allocation)\n- **Bit = 1**: Page is in use (reserved, kernel, module, etc.)\n\nEach byte holds 8 bits → 8 pages → 32 KB of physical memory. A 512 KB bitmap can track up to 16 GB of RAM.\n\n### PMM Data Structures\n\n```c\n// include/pmm.h\n#define PMM_BLOCK_SIZE 4096           // 4 KB pages\n#define PMM_BITMAP_SIZE 524288        // 512 KB bitmap → tracks 16 GB\n\n// src/mm/pmm.c\nuint8_t pmm_bitmap[PMM_BITMAP_SIZE];   // Bitmap: 1 bit per page\nstatic uint32_t total_memory_kb = 0;   // Total RAM detected\nstatic uint32_t free_blocks = 0;       // Count of free pages\nstatic uint32_t last_free_bit = 256;   // Roving pointer (optimization)\n\n// Multiboot-provided symbols\nuint64_t ramdisk_start = 0;   // Ramdisk address (Multiboot2 module)\nuint64_t ramdisk_size = 0;    // Ramdisk size in bytes\nuint8_t ramdisk_loaded = 0;   // Flag: ramdisk is loaded\n\n// Kernel boundaries (from linker script)\nextern uint32_t _kernel_start;  // Start of kernel binary\nextern uint32_t _kernel_end;    // End of kernel binary\n```\n\n### Bitmap Operations\n\n```c\n// src/mm/pmm.c - Bitmap bit manipulation\n\nstatic void pmm_set_bit(uint32_t bit) {\n    // Mark a bit as 1 (page in use)\n    if (!(pmm_bitmap[bit / 8] & (1 << (bit % 8)))) {\n        // Bit was 0 (free), now marking as 1 (used)\n        pmm_bitmap[bit / 8] |= (1 << (bit % 8));\n        if (free_blocks > 0) free_blocks--;\n    }\n}\n\nstatic void pmm_clear_bit(uint32_t bit) {\n    // Mark a bit as 0 (page free)\n    if (pmm_bitmap[bit / 8] & (1 << (bit % 8))) {\n        // Bit was 1 (used), now marking as 0 (free)\n        pmm_bitmap[bit / 8] &= ~(1 << (bit % 8));\n        free_blocks++;\n    }\n}\n```\n\n**Bit calculation example**:\n- Physical address: `0x1000` (4096 bytes)\n- Block number: `0x1000 / 4096 = 1`\n- Byte index: `1 / 8 = 0`\n- Bit index: `1 % 8 = 1`\n- `pmm_bitmap[0]`, bit 1 represents page 1 (0x1000)\n\n### PMM Initialization: Parsing Multiboot Memory Map\n\nThe bootloader (GRUB) provides a **memory map** listing which regions of RAM are available. Jarvis OS supports both **Multiboot1** and **Multiboot2**:\n\n```c\n// src/mm/pmm.c - lines 38-203\nvoid pmm_init(uint32_t magic, void* mbd_ptr) {\n    // ─────────────────────────────────────────────────────────────────────\n    // STEP 1: Initialize bitmap – mark everything as RESERVED\n    // ─────────────────────────────────────────────────────────────────────\n    // Start conservatively: assume all memory is reserved (unusable).\n    // Then parse Multiboot memory map to mark available regions as free.\n    \n    for (int i = 0; i < PMM_BITMAP_SIZE; i++) \n        pmm_bitmap[i] = 0xFF;  // All bits = 1 (all pages reserved)\n    free_blocks = 0;\n    \n    // ─────────────────────────────────────────────────────────────────────\n    // STEP 2: Parse Multiboot map based on boot method\n    // ─────────────────────────────────────────────────────────────────────\n    if (magic == 0x2BADB002) {\n        // ═════════════════════════════════════════════════════════════════\n        // MULTIBOOT 1: Legacy bootloader (BIOS)\n        // ═════════════════════════════════════════════════════════════════\n        multiboot_info_t* mbd = (multiboot_info_t*)mbd_ptr;\n        \n        // Check if memory map is provided (bit 6 of flags)\n        if (mbd->flags & (1 << 6)) {\n            // mmap_addr points to array of multiboot_mmap_entry_t\n            multiboot_mmap_entry_t* mmap = (multiboot_mmap_entry_t*)(uint64_t)mbd->mmap_addr;\n            uint32_t mmap_end = mbd->mmap_addr + mbd->mmap_length;\n            \n            while ((uint64_t)mmap < mmap_end) {\n                // Each entry describes a contiguous memory region\n                if (mmap->type == 1) {  // Type 1 = usable RAM\n                    uint64_t addr = mmap->addr;       // Start address\n                    uint64_t len = mmap->len;         // Length in bytes\n                    uint64_t end_addr = addr + len;   // End address\n                    \n                    // Mark all blocks in [addr, end_addr) as FREE\n                    while (addr < end_addr) {\n                        uint32_t block = (uint32_t)(addr / PMM_BLOCK_SIZE);\n                        if (block < (PMM_BITMAP_SIZE * 8)) {\n                            pmm_clear_bit(block);  // Clear bit = mark free\n                        }\n                        addr += PMM_BLOCK_SIZE;\n                    }\n                }\n                // Move to next mmap entry (entries are variable-size)\n                mmap = (multiboot_mmap_entry_t*)(\n                    (uint64_t)mmap + mmap->size + sizeof(mmap->size)\n                );\n            }\n        }\n        \n        // Parse framebuffer info (bit 12)\n        if (mbd->flags & (1 << 12)) {\n            screen_init_fb(\n                mbd->framebuffer_addr, \n                mbd->framebuffer_width, \n                mbd->framebuffer_height, \n                mbd->framebuffer_pitch, \n                mbd->framebuffer_bpp\n            );\n        }\n        \n        // Parse modules (ramdisk, AI brain) - bit 3\n        if (mbd->flags & (1 << 3)) {\n            multiboot1_module_t* mods = (multiboot1_module_t*)(uint64_t)mbd->mods_addr;\n            for (uint32_t i = 0; i < mbd->mods_count; i++) {\n                char* str = (char*)(uint64_t)mods[i].string;\n                if (str) {\n                    // Search for \"disk\" in module name\n                    bool found = false;\n                    int len = 0;\n                    while (str[len]) len++;\n                    for (int j = 0;  // Skip size and reserved fields\n        \n        // Parse tag-based structure (aligned 8-byte boundaries)\n        while (current_offset < total_size) {\n            multiboot2_tag_t* tag = (multiboot2_tag_t*)(\n                (uint8_t*)mbd_ptr + current_offset\n            );\n            \n            if (tag->type == 0) break;  // End of tags\n            \n            if (tag->type == 6) {  // Memory map tag\n                multiboot2_mmap_tag_t* mmap_tag = (multiboot2_mmap_tag_t*)tag;\n                uint32_t entry_size = mmap_tag->entry_size;\n                uint32_t num_entries = (\n                    mmap_tag->size - sizeof(multiboot2_mmap_tag_t)\n                ) / entry_size;\n                \n                // Iterate through mmap entries\n                uint8_t* entry_ptr = (uint8_t*)mmap_tag + \n                                    sizeof(multiboot2_mmap_tag_t);\n                for (uint32_t i = 0; i < num_entries; i++) {\n                    multiboot2_mmap_entry_t* entry = \n                        (multiboot2_mmap_entry_t*)entry_ptr;\n                    \n                    if (entry->type == 1) {  // Usable RAM\n                        uint64_t addr = entry->addr;\n                        uint64_t len = entry->len;\n                        \n                        // Mark all blocks as free\n                        uint32_t num_blocks = (uint32_t)(len / PMM_BLOCK_SIZE);\n                        for (uint64_t b = 0; b < num_blocks; b++) {\n                            uint32_t block = (uint32_t)(addr / PMM_BLOCK_SIZE) + (uint32_t)b;\n                            if (block < (PMM_BITMAP_SIZE * 8)) {\n                                pmm_clear_bit(block);\n                            } else {\n                                break;  // Outside tracking range\n                            }\n                        }\n                    }\n                    entry_ptr += entry_size;\n                }\n            } else if (tag->type == 8) {  // Framebuffer tag\n                multiboot2_fb_tag_t* fb_tag = (multiboot2_fb_tag_t*)tag;\n                screen_init_fb(\n                    fb_tag->addr, \n                    fb_tag->width, \n                    fb_tag->height, \n                    fb_tag->pitch, \n                    fb_tag->bpp\n                );\n            } else if (tag->type == 3) {  // Module tag\n                multiboot2_module_tag_t* mod_tag = (multiboot2_module_tag_t*)tag;\n                \n                // Search for \"disk\" module (ramdisk)\n                bool found = false;\n                int len = 0;\n                while (mod_tag->string[len]) len++;\n                for (int j = 0; i <= end_block; i++) {\n        pmm_set_bit(i);\n    }\n    \n    // ─────────────────────────────────────────────────────────────────────\n    // STEP 5: Protect Page 0 (NULL pointer protection)\n    // ─────────────────────────────────────────────────────────────────────\n    // NULL = 0x0. Mark page 0 as reserved so dereferencing NULL causes a fault.\n    \n    pmm_set_bit(0);\n    \n    // ─────────────────────────────────────────────────────────────────────\n    // STEP 6: Protect Ramdisk Memory\n    // ─────────────────────────────────────────────────────────────────────\n    // If bootloader loaded a ramdisk, protect its memory from allocation.\n    // The kernel's FAT32 driver reads from this ramdisk.\n    \n    if (ramdisk_loaded && ramdisk_start != 0) {\n        uint32_t rd_start_block = (uint32_t)(ramdisk_start / PMM_BLOCK_SIZE);\n        uint32_t rd_end_block = (uint32_t)(\n            (ramdisk_start + ramdisk_size + PMM_BLOCK_SIZE - 1) / PMM_BLOCK_SIZE\n        );\n        for (uint32_t i = rd_start_block; i <= rd_end_block; i++) {\n            pmm_set_bit(i);\n        }\n    }\n}\n```\n\n### Educational Breakdown: Initialization Order\n\n**Why mark everything as reserved first?** Conservative default: assume all memory is unavailable until proven otherwise (via Multiboot map). This prevents accidental use of memory that may be occupied by BIOS, firmware, or devices.\n\n**Why protect kernel memory?** If the PMM allocates pages that overlap the kernel binary, subsequent allocations will corrupt the kernel's code/data, causing crashes.\n\n**Why protect NULL (page 0)?** This is a security feature: dereferencing NULL (a common bug) will trigger a page fault instead of silently reading/writing garbage memory. The fault is caught, logged, and the system can halt gracefully.\n\n**Why support both Multiboot1 and Multiboot2?** Multiboot1 is from legacy BIOS systems; Multiboot2 is from modern UEFI. Supporting both ensures compatibility with old and new hardware.\n\n### Page Allocation\n\n```c\n// src/mm/pmm.c - lines 207-237\n\nstatic uint32_t last_free_bit = 256;  // Optimization: start searching from 1 MB\n\nvoid* pmm_alloc_block() {\n    // ─────────────────────────────────────────────────────────────────────\n    // PASS 1: Search forward from last known free bit\n    // ─────────────────────────────────────────────────────────────────────\n    // \"Roving pointer\" optimization: after allocating a block, remember where\n    // we found it. Next allocation starts nearby. This improves cache locality.\n    \n    for (uint32_t i = (last_free_bit / 8); i < PMM_BITMAP_SIZE; i++) {\n        if (pmm_bitmap[i] != 0xFF) {  // Byte has at least one free bit\n            for (int j = 0; j < 8; j++) {\n                uint32_t block = (i * 8) + j;  // Block number\n                \n                // Check if this bit is free AND we haven't wrapped around\n                if (block >= last_free_bit && !(pmm_bitmap[i] & (1 << j))) {\n                    pmm_set_bit(block);           // Mark as used\n                    last_free_bit = block + 1;    // Update roving pointer\n                    \n                    // Return physical address: block * page_size\n                    return (void*)((uint64_t)block * PMM_BLOCK_SIZE);\n                }\n            }\n        }\n    }\n    \n    // ─────────────────────────────────────────────────────────────────────\n    // PASS 2: Wrap around and search from 1 MB up to roving pointer\n    // ─────────────────────────────────────────────────────────────────────\n    // If forward search exhausted available memory, look backward.\n    // Start at 1 MB (block 256) to avoid very low memory.\n    \n    for (uint32_t i = (256 / 8); i <= (last_free_bit / 8); i++) {\n        if (pmm_bitmap[i] != 0xFF) {\n            for (int j = 0; j < 8; j++) {\n                uint32_t block = (i * 8) + j;\n                if (block >= 256 && !(pmm_bitmap[i] & (1 << j))) {\n                    pmm_set_bit(block);\n                    last_free_bit = block + 1;\n                    return (void*)((uint64_t)block * PMM_BLOCK_SIZE);\n                }\n            }\n        }\n    }\n    \n    return NULL;  // Out of memory\n}\n\nvoid pmm_free_block(void* addr) {\n    // Free a previously allocated page\n    uint32_t block = (uint64_t)addr / PMM_BLOCK_SIZE;\n    pmm_clear_bit(block);  // Mark as free\n    \n    // Reset roving pointer if we freed a block earlier than last search\n    if (block < last_free_bit) {\n        last_free_bit = block;  // Next alloc will find this newly freed block\n    }\n}\n```\n\n**Roving pointer optimization**: Instead of searching from the beginning every time, the allocator remembers the last successful allocation location. This improves cache locality: allocated pages are closer together in physical memory, reducing fragmentation and TLB misses.\n\n---\n\n## 2. Virtual Memory Manager (VMM) – 4-Level Paging\n\n### The x86_64 Paging Hierarchy\n\nIn 64-bit long mode, the CPU uses **4-level paging** to translate virtual addresses to physical addresses:\n\n```\nVirtual Address: [63..48 sign-extend] [47..39 PML4] [38..30 PDPT] [29..21 PD] [20..12 PT] [11..0 offset]\n                                       |            |            |         |        |\n                                       9 bits       9 bits       9 bits    9 bits   12 bits\n                                       ↓            ↓            ↓         ↓        ↓\nPage Table Hierarchy:           PML4[511]  → PDPT[511] → PD[511] → PT[511] → Physical Memory (4 KB)\n```\n\n**Each table has 512 entries** (2^9 bits per level). Each entry is 8 bytes (64 bits).\n\n**Address translation steps**:\n1. Extract PML4 index (bits 47–39) → lookup in CR3 (PML4 base)\n2. Extract PDPT index (bits 38–30) → lookup in PML4 entry\n3. Extract PD index (bits 29–21) → lookup in PDPT entry\n4. Extract PT index (bits 20–12) → lookup in PD entry\n5. Extract offset (bits 11–0) → add to page's physical base address\n\n### Page Table Entry Format\n\n```\nPage Table Entry (64 bits):\n[63..52 ignored] [51..12 physical_addr] [11..0 flags]\n                  └─ 40 bits address  ─┘\n\nFlags (bits 11–0):\n  Bit 0: P (Present)           – 1 = page is in memory, 0 = page fault\n  Bit 1: R/W (Read/Write)      – 1 = writable, 0 = read-only\n  Bit 2: U (User)              – 1 = user-accessible, 0 = kernel-only\n  Bit 3: PWT (Writethrough)    – 1 = writethrough caching\n  Bit 4: PCD (Cache Disable)   – 1 = caching disabled\n  Bit 5: A (Accessed)          – 1 = page has been accessed\n  Bit 6: D (Dirty)             – 1 = page has been written\n  Bit 7: PS (Page Size)        – 1 = huge page (2 MB), 0 = 4 KB\n  Bits 11..8: Available        – Free for OS use\n```\n\n### VMM Header\n\n```c\n// include/vmm.h\n#ifndef VMM_H\n#define VMM_H\n\n#include <stdint.h>\n\n#define VMM_PRESENT  0x1     // Page is present in memory\n#define VMM_WRITABLE 0x2     // Page is writable\n#define VMM_USER     0x4     // Page is accessible from user mode\n\nvoid vmm_init();\nvoid vmm_map_page(uint64_t virtual_addr, uint64_t physical_addr);\nvoid page_fault_handler(uint64_t error_code, uint64_t faulting_addr);\n\n#endif\n```\n\n### VMM Implementation\n\n```c\n// src/mm/vmm.c - lines 11-78\n\nextern uint64_t pml4_table[512];  // Temporary PML4 from loader.s\n\nvoid vmm_init() {\n    // ─────────────────────────────────────────────────────────────────────\n    // STEP 1: Map Framebuffer\n    // ─────────────────────────────────────────────────────────────────────\n    // Framebuffer is physical memory that displays on screen.\n    // Map it into kernel virtual memory so we can write to it.\n    // Identity mapping (virt = phys) keeps it simple.\n    \n    extern uint32_t* fb_ptr;       // Framebuffer base (from screen.c)\n    extern uint32_t fb_height;     // Height in pixels\n    extern uint32_t fb_pitch;      // Bytes per scanline\n    \n    if (fb_ptr) {\n        // Calculate total framebuffer size in bytes\n        uint64_t fb_size = (uint64_t)fb_height * fb_pitch;\n        \n        // Round up to next page boundary (4 KB aligned)\n        fb_size = (fb_size + 4095) & ~4095;\n        \n        // Map each 4 KB page in the framebuffer region\n        for (uint64_t offset = 0; offset < fb_size; offset += 4096) {\n            uint64_t addr = (uint64_t)fb_ptr + offset;\n            vmm_map_page(addr, addr);  // Identity map: virt = phys\n        }\n    }\n    \n    // ─────────────────────────────────────────────────────────────────────\n    // STEP 2: Map Ramdisk\n    // ─────────────────────────────────────────────────────────────────────\n    // Ramdisk is a FAT32 filesystem loaded into RAM by bootloader.\n    // Map it so kernel's FAT32 driver can read files.\n    \n    if (ramdisk_loaded && ramdisk_start != 0) {\n        uint64_t rd_size = (ramdisk_size + 4095) & ~4095;  // Round to page\n        for (uint64_t offset = 0; offset < rd_size; offset += 4096) {\n            uint64_t addr = ramdisk_start + offset;\n            vmm_map_page(addr, addr);\n        }\n    }\n    \n    // ─────────────────────────────────────────────────────────────────────\n    // STEP 3: Identity map first 16 MB\n    // ─────────────────────────────────────────────────────────────────────\n    // This ensures:\n    //   - Kernel binary (1-10 MB range) is accessible\n    //   - Bootloader temporary page tables are accessible\n    //   - Newly allocated page tables can reference themselves\n    // Without this, the kernel couldn't access its own code after\n    // switching to the new page table!\n    \n    for (uint64_t addr = 0; addr < 16 * 1024 * 1024; addr += 4096) {\n        vmm_map_page(addr, addr);\n    }\n    \n    // ─────────────────────────────────────────────────────────────────────\n    // STEP 4: Load new PML4 into CR3 (switch to new page tables)\n    // ─────────────────────────────────────────────────────────────────────\n    // CR3 (Control Register 3) holds the physical address of the PML4 table.\n    // Loading a new CR3 switches the kernel to the new virtual memory map.\n    // This is an assembly function defined in loader.s.\n    \n    vmm_load_pml4((uint64_t)pml4_table);\n    // From this point on, virtual addresses are translated via our new tables.\n}\n```\n\n### The vmm_map_page() Function – Address Translation\n\nThis is the core of the VMM. It creates (or traverses) a 4-level page table to establish a mapping from virtual to physical address:\n\n```c\n// src/mm/vmm.c - lines 43-78\n\nvoid vmm_map_page(uint64_t virtual_addr, uint64_t physical_addr) {\n    // ─────────────────────────────────────────────────────────────────────\n    // STEP 1: Extract indices from virtual address\n    // ─────────────────────────────────────────────────────────────────────\n    // Each index is 9 bits (range 0–511).\n    \n    uint64_t pml4_idx = (virtual_addr >> 39) & 0x1FF;   // Bits [47:39]\n    uint64_t pdpt_idx = (virtual_addr >> 30) & 0x1FF;   // Bits [38:30]\n    uint64_t pd_idx   = (virtual_addr >> 21) & 0x1FF;   // Bits [29:21]\n    uint64_t pt_idx   = (virtual_addr >> 12) & 0x1FF;   // Bits [20:12]\n    \n    // ─────────────────────────────────────────────────────────────────────\n    // STEP 2: Walk/build PML4 → PDPT → PD → PT hierarchy\n    // ─────────────────────────────────────────────────────────────────────\n    \n    // ═ LEVEL 1: PML4 (already loaded in CR3) ═\n    // Check if PML4[pml4_idx] is present (points to a valid PDPT)\n    if (!(pml4_table[pml4_idx] & VMM_PRESENT)) {\n        // PML4 entry is empty → allocate new PDPT table\n        uint64_t* new_pdpt = (uint64_t*)pmm_alloc_block();\n        if (!new_pdpt) return;  // Out of memory\n        \n        // Zero out the new PDPT (512 entries × 8 bytes)\n        for (int i = 0; i < 512; i++) \n            new_pdpt[i] = 0;\n        \n        // Set PML4[pml4_idx] to point to new PDPT\n        // Flags: P (present) | RW (writable)\n        pml4_table[pml4_idx] = ((uint64_t)new_pdpt) | (VMM_PRESENT | VMM_WRITABLE);\n    }\n    \n    // Extract the PDPT address from PML4 entry\n    // Mask out lower 12 bits (flags)\n    uint64_t* pdpt = (uint64_t*)(pml4_table[pml4_idx] & ~0xFFFULL);\n    \n    // ═ LEVEL 2: PDPT ═\n    // Check if PDPT[pdpt_idx] is present\n    if (!(pdpt[pdpt_idx] & VMM_PRESENT)) {\n        // Allocate new PD (Page Directory) table\n        uint64_t* new_pd = (uint64_t*)pmm_alloc_block();\n        if (!new_pd) return;\n        for (int i = 0; i < 512; i++) \n            new_pd[i] = 0;\n        pdpt[pdpt_idx] = ((uint64_t)new_pd) | (VMM_PRESENT | VMM_WRITABLE);\n    }\n    \n    uint64_t* pd = (uint64_t*)(pdpt[pdpt_idx] & ~0xFFFULL);\n    \n    // ═ LEVEL 3: PD (Page Directory) ═\n    // Check if this entry is already a huge page (2 MB)\n    if ((pd[pd_idx] & VMM_PRESENT) && (pd[pd_idx] & 0x80)) {\n        // PS bit (bit 7) = 1 → this is a 2 MB huge page\n        // Don't overwrite it with 4 KB page\n        return;\n    } else if (!(pd[pd_idx] & VMM_PRESENT)) {\n        // Allocate new PT (Page Table)\n        uint64_t* new_pt = (uint64_t*)pmm_alloc_block();\n        if (!new_pt) return;\n        for (int i = 0; i < 512; i++) \n            new_pt[i] = 0;\n        pd[pd_idx] = ((uint64_t)new_pt) | (VMM_PRESENT | VMM_WRITABLE);\n    }\n    \n    uint64_t* pt = (uint64_t*)(pd[pd_idx] & ~0xFFFULL);\n    \n    // ═ LEVEL 4: PT (Page Table) ═\n    // Set final mapping: PT[pt_idx] = physical_addr | flags\n    // Mask physical address to 4 KB boundary\n    pt[pt_idx] = (physical_addr & ~0xFFFULL) | (VMM_PRESENT | VMM_WRITABLE);\n    \n    // ─────────────────────────────────────────────────────────────────────\n    // STEP 3: Invalidate TLB entry\n    // ─────────────────────────────────────────────────────────────────────\n    // TLB (Translation Lookaside Buffer) is CPU cache for recent translations.\n    // After updating a page table, flush the TLB entry for this address.\n    // Otherwise, CPU might use stale cached translation.\n    \n    asm volatile(\"invlpg (%0)\" : : \"r\"(virtual_addr) : \"memory\");\n}\n```\n\n### Educational Breakdown: Why This Design?\n\n**Why lazy table allocation?** We don't pre-allocate all 4 levels for every virtual address. Instead, tables are allocated on-demand (lazy). When mapping `0x7FFFFFFF`, if PDPT[0] doesn't exist, we allocate it. This saves memory: unused address ranges don't consume table space.\n\n**Why check for huge pages?** The bootloader (loader.s) set up 2 MB huge pages for the initial identity map (faster, simpler). When vmm_map_page() is called, it checks if a PDPT entry already points to a 2 MB page. If so, it doesn't try to overwrite it with 4 KB pages—they don't mix.\n\n**Why TLB invalidation?** The CPU caches address translations. After updating a page table, the TLB still has the old translation cached. The `invlpg` instruction flushes that specific entry, forcing the CPU to re-translate the address using the new tables.\n\n---\n\n## 3. Virtual-to-Physical Translation Example\n\nLet's trace a concrete example: mapping virtual address `0x0000000000005000` to physical address `0x0000000000010000`.\n\n**Virtual address**: `0x0000000000005000`\n\n```\nBinary: 0000 0000 0000 0000 0000 0000 0000 0000 0000 0101 0000 0000 0000 0000\nBits:   [63..48 zeros for sign-ext] [47..39] [38..30] [29..21] [20..12] [11..0]\n                                       000       000      000      005      000\n\nExtraction:\n  PML4 index = (0x5000 >> 39) & 0x1FF = 0\n  PDPT index = (0x5000 >> 30) & 0x1FF = 0\n  PD index   = (0x5000 >> 21) & 0x1FF = 0\n  PT index   = (0x5000 >> 12) & 0x1FF = 5\n  Offset     = 0x5000 & 0xFFF = 0\n```\n\n**Page table walk**:\n\n1. Load `pml4_table[0]` (PML4 index=0)\n   - Contains: `0x1001 | 0x3` (physical address of PDPT, flags present+writable)\n   - PDPT address: `0x1001000`\n\n2. Load `pdpt[0x1001000][0]` (PDPT index=0)\n   - Contains: `0x2001 | 0x3` (physical address of PD)\n   - PD address: `0x2001000`\n\n3. Load `pd[0x2001000][0]` (PD index=0)\n   - Contains: `0x3001 | 0x3` (physical address of PT)\n   - PT address: `0x3001000`\n\n4. Load `pt[0x3001000][5]` (PT index=5)\n   - Contains: `0x10000 | 0x3` (physical address of page)\n   - Physical page: `0x10000`\n\n5. Add offset: `0x10000 + 0 = 0x10000` ✓\n\n---\n\n## 4. Page Fault Handling\n\nWhen the CPU accesses a page that isn't mapped or doesn't have proper permissions, it triggers a **page fault interrupt**. The kernel can inspect the fault and decide how to handle it.\n\n```c\n// src/mm/vmm.c - lines 80-122\n\nvoid page_fault_handler(uint64_t error_code, uint64_t faulting_addr) {\n    // ─────────────────────────────────────────────────────────────────────\n    // STEP 1: Disable further interrupts and print panic header\n    // ─────────────────────────────────────────────────────────────────────\n    \n    asm volatile(\"cli\");  // Disable interrupts\n    \n    print_string(\"\\n\\n\\n\");\n    print_string(\"!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!\\n\");\n    print_string(\"          KERNEL PANIC: PAGE FAULT               \\n\");\n    print_string(\"!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!\\n\\n\");\n    \n    // ─────────────────────────────────────────────────────────────────────\n    // STEP 2: Print faulting address (64-bit value)\n    // ─────────────────────────────────────────────────────────────────────\n    \n    print_string(\"Faulting Address: \");\n    kprint_hex((uint32_t)(faulting_addr >> 32));  // Upper 32 bits\n    kprint_hex((uint32_t)faulting_addr);          // Lower 32 bits\n    print_string(\"\\n\");\n    \n    // ─────────────────────────────────────────────────────────────────────\n    // STEP 3: Decode error code\n    // ─────────────────────────────────────────────────────────────────────\n    // Page fault error code is a bitmask indicating what caused the fault.\n    \n    print_string(\"Error Code: \");\n    kprint_hex((uint32_t)error_code);\n    print_string(\" (\");\n    \n    int present  = !(error_code & 0x1);   // Bit 0: P flag\n    int rw       = error_code & 0x2;      // Bit 1: R/W flag\n    int us       = error_code & 0x4;      // Bit 2: U flag\n    int reserved = error_code & 0x8;      // Bit 3: Reserved bit\n    int id       = error_code & 0x10;     // Bit 4: Instruction fetch\n    \n    // Print human-readable error description\n    if (present)  print_string(\"not-present \");     // P=0 → page not in memory\n    if (rw)       print_string(\"read-only \");       // Write to read-only page\n    if (us)       print_string(\"user-mode \");       // User code accessed kernel page\n    if (reserved) print_string(\"reserved \");        // CPU reserved bits violated\n    if (id)       print_string(\"instruction-fetch \"); // Instruction fetch from non-exec page\n    print_string(\")\\n\\n\");\n    \n    // ─────────────────────────────────────────────────────────────────────\n    // STEP 4: Halt system (graceful countdown)\n    // ─────────────────────────────────────────────────────────────────────\n    \n    print_string(\"The system will automatically reboot in 5 seconds...\\n\");\n    \n    for (int i = 5; i > 0; i--) {\n        print_string(\"Rebooting in \");\n        kprint_dec(i);\n        print_string(\"... \\n\");\n        \n        // Delay (busy wait)\n        for (volatile uint32_t j = 0; j < 100000000; j++) \n            asm volatile(\"nop\");\n    }\n    \n    print_string(\"Rebooting now!\\n\");\n    extern void sys_reboot();\n    sys_reboot();\n}\n```\n\n### Error Code Interpretation\n\n| Bit | Flag | Meaning |\n|-----|------|----------|\n| 0 | P | Page is present in memory (0) or not present (1) |\n| 1 | R/W | Caused by write (1) or read (0) |\n| 2 | U | Caused by user-mode (1) or kernel-mode (0) |\n| 3 | RSVD | CPU reserved bit was set |\n| 4 | I/D | Caused by instruction fetch (1) or data access (0) |\n\n**Common scenarios**:\n- **P=0, R/W=0**: Page not present → demand paging (allocation needed)\n- **P=1, R/W=1**: Write to read-only page → protection violation\n- **P=1, U=1**: User code accessed kernel page → privilege violation\n\n---\n\n## ✅ Summary\n\nIn this phase, you learned:\n\n✅ **Bitmap-based physical memory tracking** – efficient, simple, scalable  \n✅ **Multiboot memory map parsing** – supporting both Multiboot1 and Multiboot2  \n✅ **Reserved memory protection** – kernel, NULL page, modules, ramdisk  \n✅ **4-level page table hierarchy** – PML4 → PDPT → PD → PT  \n✅ **Virtual-to-physical translation** – index extraction, lazy table allocation  \n✅ **TLB invalidation** – ensuring CPU uses updated mappings  \n✅ **Page fault handling** – error code decoding, privilege enforcement  \n✅ **Roving pointer optimization** – improving allocation performance  \n\n**Next**: [Phase 4: Interrupts & APIC Configuration](./04-interrupts-and-apic.md) – Learn how the kernel sets up exception and interrupt handling using GDT, IDT, and APIC.\n\n---\n\n**Exercises**:\n1.
